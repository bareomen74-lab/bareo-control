# BAREO · Actualizar control

Herramienta para actualizar el control de pedidos y finanzas de BAREO con los reportes de Dropi.
Todo se procesa en el navegador: ningún archivo ni dato se sube a internet.

Uso: abrir la página en Google Chrome o Microsoft Edge → elegir la carpeta del control → soltar los reportes de Dropi → "Actualizar mi control".
